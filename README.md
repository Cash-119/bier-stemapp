# Stembureau Kos

Stemsite voor onze vakantie naar Kos. Alle opties uit de groepsapp op een rij, met prijzen, voor- en nadelen, en live stemmen.

- **Vaste opties en vragen:** `data.js`
- **Stemmen, antwoorden en toegevoegde opties:** Firebase Firestore (config in `config.js`, regels in `firestore.rules`)
- **Hosting:** GitHub Pages (Settings → Pages → Deploy from branch → `main` / root)
